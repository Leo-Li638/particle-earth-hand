### 1.1 关键构图结论
1. **地球永远偏右**（u≈0.56），左边 1/5 留给 HUD 面板——布局是"左文字列 + 右巨球"。
2. **题注是屏幕空间固定位置**（v≈0.84/0.90），**不随球体缩放移动**——说明题注是 HTML/CSS 覆盖层，不是 3D 精灵。实测在球 R=115px 与 R=212px 两种状态下题注位置几乎一致。
3. 点阵模式相机比流星雨模式**近约 1.8 倍**（R 0.48H vs 0.27H），球体被视口上下裁切。
4. 球心 v 有轻微漂移（0.46→0.54），可能是相机缓慢移动/呼吸，不是硬性规范。

## 2. 两种模式的差异清单

| 维度 | 点阵制图模式（CHART） | 流星雨模式（METEOR） |
|---|---|---|
| 地球材质 | **点云球**（Points）：只画陆地，海洋为平滑深蓝面（几乎无点）；无云层贴图 | **光滑着色球**：真实地表贴图（大陆/海洋）+ 云层，蓝白高光，近白陆地 |
| 地球本体 | 深蓝球体 + 白蓝点阵；夜面/背光侧点变暗 | 深蓝球 + 近白陆地/云 + 海洋中蓝；右侧边缘有**强烈暖金轮廓光** |
| 点阵 | 有（核心特征） | 无 |
| 外圈光晕 | 弱：球缘亮边 + 大面积暗蓝雾 | 强：**2 层**（球缘亮环 + 1.55-1.63R 蓝色雾环） |
| 轨道环 | 隐约大圆弧（不确定） | 同心光环，无倾斜环 |
| 太阳光晕 | 弱/无 | 左上暖白光团 + 强 bloom |
| 城市灯 | 金色暖白节点 + **辉光**（每城一个亮团），带极小城市名标签 | 满天**小金点**（等地表夜景灯），更小更密，无标签 |
| 连线弧 | **核心特征**：青蓝色细弧从焦点城市向其他城市呈放射扇面，几十条，带流动亮点 | 无连线 |
| 题注 | 城市名：中文（大）+ 英文大写（小、宽字距） | "流星雨" / "METEOR SHOWER" |
| 星空/流星 | 星空仍在（较暗），流星少 | **流星多且明显**：短亮条 + 长尾，频率高 |
| 相机 | 很近（R=0.48H），球被裁切 | 中（R=0.26-0.34H），整球可见 |
| 场景标签 | 城市旁有极小白字标签（2-3px 高，不可辨读） | 无 |
| 切换瞬间 | t≈0 / 13.5-15.5s：大量密集白色弧线**爆发**（像流星雨炸开/连线炸开），持续 0.5-1s，落点带 glow | — |

**时间线（题注顺序，t=秒）**：t0 无题注（密集弧爆发）→ t5-6 流星雨 → t16 上海 → t17-18 东京 → t19 旧金山 → t20 纽约 → t21 伦敦 → t22 巴黎 → t23 伊斯坦布尔 → t24 莫斯科。每个城市约停留 1s（视频被剪过，不代表真实 dwell）。

## 4. 点阵特征（chart 模式，最重要）

| 特征 | 测量值 | 置信 |
|---|---|---|
| 排列规则 | **经纬网格**（lat/long grid）：横向为纬线行、纵向为经线列，投影后自然汇聚到两极；**不是随机撒点** | 高 |
| 点间距（pitch） | 0121（R=212px）：**≈4.0-4.5px**（自相关峰值 lag 4-5px）；即 pitch/R ≈ **0.019-0.021** ⇒ 全周约 **150-160 个纬度行**（当前实现 DOT_ROWS=158 正好吻合） | 高 |
| 点直径 | **1.5-1.8px** ≈ 0.38-0.45 × pitch | 高 |
| 陆海差异 | 陆地：密+亮（#cce0f7~#ffffff）；**海洋：几乎无点**，只剩平滑深蓝面（真·仅陆地） | 高 |
| 边缘加密 | **是**：投影压缩使球缘的点排成亮条纹/亮边（视觉上形成一圈亮环）；不是额外加点 | 中高 |
| 明暗 | 有昼夜：受光面（右上）点全亮，背光面（左下）点变暗甚至消失；过渡区可见"晨昏线" | 中高 |
| 城市灯来源 | chart 模式：**独立金色发光节点**（不是贴图里的点），每城一个团+bloom；流星雨模式：中小金点近似"夜空灯光贴图"散布在陆地上 | 中 |
| 点大小是否随距离 | 视口内点大小基本恒定，接近屏幕空间恒定（sizeAttenuation 弱） | 中 |

## 5. HUD 逐行标签与数值

### 5.1 结构（可确认）
- 位置：左上面板，u 0..0.21，v 0..0.55；**无面板底色/边框**（直接叠在星空上），文字白色。
- 顶部标题块：一枚小图标 + **2 行标题**（第 1 行较大 ≈6-7px 高，第 2 行 ≈4-5px），c011.png 目视为「**深空制图仪**」+「第 X 号 / 世界 X 号」——**低置信**。
- 标题块下方为键值行列表：**2 列布局**（左列标签、右列数值），行距 **≈9-10px**（= 0.021-0.023 H_vp，即设计稿 1000px 高时约 21-23px 行距），字号 5-6px。
- 行数约 **12-14 行**，可分为 2-3 组（中间有分组间距）。
- 最左侧 x 0..14 还有一条**很窄的装饰列**（竖向刻度/竖排小字，不可辨读）——低置信，可能是分辨率标尺。
- 面板中部右侧有一枚**金色高亮小徽章**（约 8x5px），疑为"当前选中城市"标记。
- 左下角单行提示：极小字（≈5-6px 高），含 4-6 段用 `| ` / `▸` 分隔的键值，个别数值带色；**内容不可辨读**。

### 5.2 可辨读数值（来自帧 0040 的最佳读数，仍为**低置信**）
| 行 | 读数 | 置信度 |
|---|---|---|
| 1 | `50 fps` | 中（清晰可辨） |
| 2 | 疑似 `帧率 · 1 月序` / `帧率 · X 月` | 低 |
| 3 | `13,414` | 中 |
| 4 | `3,144` | 中 |
| 5 | `5 颗` / `5 颗` | 中 |
| 6 | `1 颗` | 低 |
| 7 | `271 条`（也可能是 `271 m`） | 低 |
| 8 | `73%` | 中 |

> 任务描述里给出的标签候选（经度/纬度/距率/帧率/手势/焦点/城市/卫星/空间区/测距/日期/信号）与"约 12-14 行、2 列"的结构一致，可作为复原依据，但**具体行序无法从视频确认**。
> 建议：按产品语义自行定行序，视觉上保持"左标签暗白 + 右数值亮白 + 等宽数字 + 行距 0.022H"，即视为达标。

### 5.3 视觉样式要点（高置信）
- 字体：无衬线、**数字用等宽**（13,414 / 3,144 对齐），中文标签更细。
- 颜色：白；标签 ~60% 透明，数值 ~90%；不允许面板背景块。
- 无边框、无 panel bg、无分隔线（或极弱 1px 线）。

## 9. "必须匹配"优先级清单

### P0（不匹配就"不像"）
1. **构图**：地球圆心 u≈0.56 / v≈0.50；chart 模式球半径 **0.48 H_vp**（上下裁切）；meteor 模式 **0.27-0.34 H_vp**。
2. **点阵球质感**：仅陆地有点（海洋干净平滑）；经纬网格；pitch/R≈0.02、点径≈0.4pitch；受光面亮白、背光面变暗；球缘点被压成亮条纹。
3. **题注**：屏幕空间固定位置（中文中心 v≈0.85、英文 v≈0.90），水平对齐球心 x；中文 0.045H_vp 白色粗体；英文大写、0.021H_vp、宽字距（0.3-0.4em）；两模式题注文案切换。
4. **两模式区分**：chart=点阵+连线弧+城市灯；meteor=光滑贴图球+云+双层蓝光晕+月球+流星。
5. **背景与光晕层次**：背景近黑 #0b0e1a，球外有暗蓝大气雾（#1d3561 主体），meteor 模式可见 1.55-1.63R 的圆环边界。

### P1（明显影响观感）
6. 主光从**右上**来；右缘暖金 rim light；左下暗部。
7. 连线弧：中蓝 #3a82c8 细线（1px）+ 外晕，几十条从焦点城市放射，带流动亮点。
8. 城市灯：暖白 #fff2dd 核心 + 琥珀外晕的发光团（bloom），不是纯色圆点。
9. bloom 强度：点/城市/题注明显外溢但背景保持深黑（strength 0.8-1.2 / threshold 0.15-0.25，见下）。
10. 月球：直径 0.15R、右下 (u0.75,v0.87)、距地心 1.7R、灰白带环形山贴图 + 柔光。
11. 流星：20-40px 细线、亮头渐隐尾、同屏 3-6 条、右上→左下。
12. HUD 面板：左上层级（标题块 2 行 + 12-14 行键值），行距 0.022H，无面板底色。

### P2（锦上添花）
13. 星空 150-400 颗 + 少量亮星带星芒。
14. 左下角单行提示（多段 `|` 分隔的小字，50% 透明）。
15. 切换瞬间的弧线爆发（0.5-1s）。
16. HUD 金色选中徽章、极弱装饰刻度列。
17. 相机极缓慢推进/呼吸（球半径从 0.26H 到 0.34H）。

## 11. 不确定项 / 复查方法

1. **HUD 面板逐行文案与数值**：全片失焦，只有 8 个数值可辨（§5.2）。若要更高置信，唯一办法是拿到该网页应用的源码/截图，视频里不存在。
2. **倾斜轨道环**：是否存在真正的 3D 倾斜环无法确认（只看到同心圆；倾斜环会呈椭圆）。若产品需要"倾斜轨道环"，建议用 1.5-1.7R 的椭圆环、倾角 15-25°，低不透明度（0.1-0.2），不违背参考的整体观感。
3. **太阳光晕位置**：左上暖白光团与手机反光（灯管条+圆斑）难以完全区分，置信中。物理反光特征：长条水平亮带 + 圆暖斑，且**随手机移动而相对 UI 位移** → **不要复刻**。
4. **第三行小字**：存在但不可辨，建议用时间（`08:07:16`）或经纬度，视觉占位即可。
5. **月亮在 chart 模式**：被题注/裁切遮挡，不确定是否常驻。
6. **点间距**：自相关给出 4-5px 周期，视觉 3.8-4.0px；两者差异来自透视与压缩，取 4.2px ±10% 即 pitch/R=0.02。
